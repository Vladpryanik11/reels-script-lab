# Reels Script Lab

**Универсальный движок для Reels/Shorts.** Режим по умолчанию — universal; отдельные профили подключаются только по явному запросу.

## Текущее состояние GitHub

Это **ветка поэтапного импорта v0.8.2**. Здесь сохранены реестр, ограничения методологии и исторические материалы, но **полная папка исходников должна быть импортирована из верифицированного ZIP**. До окончания переноса сборка не является установочным релизом.

| Агент | Собственный объект |
|---|---|
| Hook Formula + Reviewer | Формулы и обучающие статьи, механика удержания |
| Human Language + Reviewer | Живая русскоязычная речь, редактирование без разрушения хука |
| Structure + Reviewer | Семь выбранных по смыслу драматургий SRC-01…07 |
| Rehook + Reviewer | Шесть механизмов Tatam, самостоятельный отбор |
| Research, Script, CTA, Final Review | Факты, сюжет, CTA и согласованность всего ролика |

**Нельзя** делать хук напрямую из комментария вместо методологии; сводить все драматургии к пяти полям; заменять позднее сценарный review проверкой JSON; выдавать внутреннее self-review за независимую оценку.

## Проверка

После полной загрузки ZIP: `python scripts/verify_baseline.py --strict` и `python -m unittest discover -s tests -p 'test_*.py' -q`. Статус тестов проверять по фактическому выводу GitHub Actions; старые отчёты — исторические.
