# Reels Script Lab

Универсальный движок для исследования, написания и проверки сценариев коротких видео (Reels, Shorts).

> **Статус:** начальная настройка GitHub-репозитория. Восстановленная исходная сборка v0.8.2 импортируется и проверяется в отдельной ветке. Не считать этот репозиторий готовым плагином до завершения импорта и ревью.

## Зафиксированное разделение ответственности

- **Hook Formula Agent** — хуки строго по согласованной методологии и первоисточникам.
- **Human Language Agent** — самостоятельная работа с живой русскоязычной речью; не подменяет формулы.
- **Structure Agent** — выбор одной из семи драматургий по содержанию; не фиктивные ярлыки SRC.
- **Rehook Agent** — шесть смысловых механизмов; интрига, а не повтор хука.
- **Research, Script, CTA, Review** — независимые контракты и проверка обоснованности, драматургии и языка.
- **Universal** — профиль по умолчанию; нишевые профили подключаются только явно.

## Правило разработки без потерь

Все изменения — в отдельных ветках и через Pull Request. Нельзя сокращать согласованные первоисточники или заменять методологии короткими пересказами. Отчёты автотестов не равны проверке качества сценариев.

**Предыдущая восстановленная локальная версия:** v0.8.2, готовый на момент переноса skills-only прототип. Отдельные автономные AI-агенты и подключённый Threads API не заявляются.
