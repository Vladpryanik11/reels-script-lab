# DECISIONS — согласованные неизменные требования

Дата фиксации: 2026-10-21. Изменять только через явное согласование и PR.

1. **Универсальность.** Плагин применим к любой нише. `profiles/universal.md` по умолчанию; отраслевые примеры не являются общими правилами.
2. **Методология хуков — отдельно.** Формулы из подтверждённых материалов и пользовательского каталога; реальные комментарии не служат источником формул.
3. **Human Language — отдельно.** Изучает доступные русскоязычные посты/ответы/форумы ради языка и ритма. Сохраняет механизм хука и факты; после редакции — новый Hook Reviewer.
4. **Research — отдельно.** Никаких выдуманных фактов, медицинских выводов из комментариев, ложного чтения недоступных страниц. Тип доказательств подбирается к предмету, а не всегда психология.
5. **Драматургия сохраняется.** Семь структур SMMplanner SRC-01…07; сценарий обязан реализовать выбранную, а не только назвать её.
6. **Рехук сохраняется.** Шесть техник Tatam; он создаёт новый мотив досмотреть, не обязан быть вопросом. Слабые кандидаты отклоняются.
7. **Три разные ветки.** Три полноценные истории, а не три вариации первой строки; цель Reels и CTA согласованы.
8. **Зафиксированные фразы не переписывать.** Если пользователь утвердил текст/каталог, требуется отдельное разрешение на смысловое изменение.
9. **Независимость проверки.** Формальный PASS ≠ редакторский PASS ≠ опубликованное удержание. Не заявлять автономных агентов, если они не развёрнуты.
10. **Никаких потерь при миграциях.** `methodology-originals/` хранит неизменённые байты; любые правки рабочих ссылок отдельным diff с явным объяснением.
11. **Работа только через PR.** `main` — стабильная версия. Не объединять сокращение согласованных методик, не прошедшее ревью.

Оригинальные SHA-256 ключевых файлов: `baseline/v0.8.2.json`. Предыдущие отчёты сохранены в `docs/history/` как исторические документы, не текущий статус тестов.
