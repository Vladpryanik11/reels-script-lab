# Reels Script Lab Universal — методология восстановлена (v0.8.2)

Это точечное восстановление подробных ранних методологических правил поверх v0.8.1. НЕ новое перепроектирование и не независимый AI-runtime.

Главное: Hook Formula Agent учится по подтверждённым учебным источникам; Human Language Agent **только** редактирует естественность русской речи; Structure Agent выбирает одну из 7 SMMplanner-драматургий, Rehook Agent — из 6 приёмов Tatam; Script Agent реализует выбранную историю, а не «пять полей»; CTA Agent выбирает обоснованное действие. Формулы, факты и язык остаются разными потоками.

## Канонические инструкции внутри установочного ZIP

- `reels-script-lab/skills/reels-script-lab/SKILL.md` — точка входа.
- `references/12-hook-formula-library.md`, `references/21-hook-methodology.md`, `references/22-hook-reviewer.md` — Hook Agent.
- `references/11-human-language-agent.md` — отдельный речевой редактор.
- `references/13-structure-methodology.md` и `references/14-structure-reviewer.md` — семь SRC-конструкций с условиями и проверками.
- `references/15-rehook-methodology.md`, `references/16-rehook-reviewer.md`, `references/18-rehook-generator.md`, `references/19-rehook-orchestrator.md`, `references/20-rehook-reviewer-prompt.md` — шесть TR-техник, пул кандидатов и слепое ревью.
- `references/17-script-storytelling.md` — Jenny Hoyos, Postium, ритм и исполняемая драматургия.
- `references/23-cta-methodology.md` — CTA и reviewer.
- `scripts/pipeline_gate.py` — структурные признаки, проверка источников методологии, smoke-тесты пустых фраз.
- `methodology-originals/` — исходные документы ранних версий, **сохранённые дословно** для происхождения и сравнения; их отраслевые примеры не являются правилами универсального ядра.

## Выполнение и ограничения

Команда: `python -m unittest discover -s tests -p 'test_*.py' -q` из папки workspace. `python reels-script-lab/skills/reels-script-lab/scripts/pipeline_gate.py fixtures/pipeline-packet.example.json` — пример структурного валидатора.

**Нельзя путать** field-level PASS с художественным PASS. Отдельные AI-агенты, проверенное независимое ревью и надёжное чтение реальных постов не запущены; старый запуск jobsearch больше не проходит строгую проверку. Полный статус см. `docs/METHODOLOGY-RESTORATION-v0.8.2.md`.
