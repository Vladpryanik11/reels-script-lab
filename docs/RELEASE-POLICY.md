# Release policy / No-loss gates

1. Каждое изменение в отдельной ветке; для импорта исходников — `import/v0.8.2-baseline`.
2. Сохранить оригинальные документы в `reels-script-lab/skills/reels-script-lab/methodology-originals/`; не перезаписывать при генерации файлов.
3. Сверять `baseline/v0.8.2.json` с фактическими SHA-256. Для первоначального импорта все 75 файлов должны присутствовать, а защищённые — совпадать побайтно.
4. Сравнивать активные ссылки, число структур SRC-01…07, техники Tatam, роли Hook и Human Language и сценарные ветки. Не «чинить» тесты ради зелёного результата.
5. Запускать структурные тесты **и** отдельный тест качества на свежих примерах нескольких несвязанных ниш.
6. Провести независимое содержательное ревью. Отсутствие реального AI-runtime/разрешений источников оформлять как ограничение.
7. Не собирать релиз из неподтверждённого состояния. Маркировка v0.8.2 означает историческую базу; версии последующих исправлений увеличивать.
8. GitHub Actions и CODEOWNERS проверять после импорта. Сам файл CODEOWNERS **не включает защиту ветки автоматически**; установить required checks/required review в Settings → Branch protection (если доступно).

## Не удалять
- Согласованные пользовательские источники и первоначальные тексты;
- 7 описаний сюжетной структуры;
- 6 механизмов рехука;
- авторское содержание прошедшего ревью;
- исходники и результаты негативных тестов.
