# Reels Script Lab v0.7 — план реализации и статусы

Дата: 2026-10-20. Цель: универсальный skills-only конвейер, который не маскируется под действующих автономных ИИ-агентов.

## 1. Изоляция общего ядра и корректная упаковка
- [x] Собрать отдельный чистый пакет `reels-script-lab/` с одной точкой входа.
- [x] Оставить профиль universal по умолчанию и профильные настройки опциональными.
- [x] Убрать психологическую тематику из инструкций общего ядра.
- [x] Проверить ссылки на файлы, JSON manifest и версию после упаковки.

## 2. Защита от фиктивной «живой речи»
- [x] Аудит входных записей: HTTPS URL, canonical identity, дата, роль автора, достаточность кириллицы и текстового сигнала, дубликаты.
- [x] Разделить «материал представлен», «структурно проверен», «источник действительно открыт» и «человеческая редакция».
- [x] Выбирать источники по аудитории и теме, а не только по отрасли.
- [x] При невозможности полного чтения не присваивать `VERIFIED`.

## 3. Полный универсальный цикл
- [x] Справочники ролей Voice, Research, Hook+Speech Editor, Structure, Rehook, Script, CTA, Final.
- [x] Условная проверка фактов; творческие сценарии без научных источников допустимы.
- [x] Единый offline stage contract с тремя разными ветками и locked text.
- [x] Технический gate: незавершённые review stages и факты блокируют «готов к выпуску».

## 4. Поведенческое качество
- [x] Противодействие AI-slop на каждом текстовом шаге (нельзя списком запрещённых слов выдать успех).
- [x] Отказ от слабой ветки, запрет автоматического PASS, 5 разнопрофильных контрактных фикстур.
- [ ] Живой слепой тест 2–3 независимых редакторов; нужна фактическая обратная связь людей.
- [ ] Три реальных независимых reviewer-run; нет подключенного агентоисполнителя.

## 5. Упаковка, тесты, честный выпуск
- [x] Новый ZIP с source-of-truth версией 0.7.0; без dev-дерева и pycache.
- [x] Автотесты: негативные случаи источников, профили, контракты, конечные gates и ZIP.
- [ ] Прямой многоплатформенный runtime fetch с подтверждённым доступом; нужны поддерживаемые tools/браузер Work или разрешённые API.
- [ ] Эксплуатационный запуск плагина в ChatGPT после явной установки пользователем.

Статусы `[x]` в этом файле указывают на реализуемые в текущей сборке модули; окончательная верификация производится тестами и отчётом ниже. Не заявлять развернутого MCP, выполненного AI-review или подтверждённого корпуса без реального запуска.
