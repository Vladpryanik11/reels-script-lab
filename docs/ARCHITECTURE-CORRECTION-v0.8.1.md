# Reels Script Lab v0.8.1 — ревью границ компетенций

## Корневая ошибка v0.8

Ошибка: реальные бытовые обсуждения использовались как тематическая заготовка для хуков. Получилось «комментарий → хук». Пользователь требует другой процесс: **сила хука берётся из специальной методологии и утверждённых формул; разговорность — из отдельного языкового агента**.

## Исправленный поток

```text
                     +-- Hook Formula Agent -> Hook Reviewer --+
Brief + Fact Packet -+                                         +-> Voice edit -> Hook Reviewer again -> Lock
                     +-- Human Language Agent -> Language Map -+
                                     |
                          Human Language Reviewer
```

Второй поток не разрабатывает сюжетные крючки и не утверждает их эффективность. Первый поток не называет бытовые комментарии формулами. При желании Audience Research может отдельно исследовать потребности, но этот результат не заменяет формулы. Все роли универсальны для отраслей.

## Ответственность и запреты

| Роль | Вход | Создаёт | Запрещено |
|---|---|---|---|
| Hook Formula Agent | пользовательские учебные ссылки, бриф, проверенные факты | формулу, draft, крючок, первый кадр, обещание | считать обсуждения библиотекой формул |
| Hook Reviewer | формула, draft, сценарное обещание | конкретный PASS/REJECT качества крючка | заменять оценку формулы «звучит по-человечески» |
| Human Language Agent | тексты, комментарии, стиль автора и draft | редакцию лексики, синтаксиса, устного ритма | придумывать интригу, менять payoff, формулу, факт |
| Human Language Reviewer | style_map и редакцию | оценку естественности и звучания | утверждать хук как эффективный |
| Hook Reviewer after edit | исходная формула и итог | проверку сохранности интриги | принимать стилизацию без повторной проверки |

## Проверки

- v0.8.1: 18 отдельных unit-тестов проверяют, что текст комментария не становится источником формулы, не принимается произвольный `formula_id`, языковой агент не подменяет механику, редакция снова проходит методологическое ревью. Добавлена 1 проверка целостности релизного ZIP.
- Весь актуальный набор v0.8.1: **74/74 PASS** после упаковки.
- Локальный код умеет проверить только поля и переходы, не «силу» хука и не сходство с реальной речью. Без реальных LLM runs, авторизованного чтения и слепой редакторской оценки — `PREVIEW_ONLY`.
- Старые 9 примеров из разных ниш **НЕ тест формул хуков**: остаются в отчёте как антипример неверного соединения ролей.
