# Универсальный профиль — default

Тон: определяется актуальным брифом, а не отраслью. Нейтральный старт — естественная разговорная русская речь, уважительная, с правдоподобными ситуациями, без рекламного канцелярита. Не предполагать, что аудитория испытывает определённые эмоции, знает жаргон или нуждается в психологическом объяснении.

Приоритеты: наблюдаемое действие → узнавание/практическая ценность → интрига → раскрытие → осмысленный CTA. Формулы — инструменты, их выбор необязателен. Нет обязательного фиксированного количества научных источников, когда нет проверяемых утверждений.
