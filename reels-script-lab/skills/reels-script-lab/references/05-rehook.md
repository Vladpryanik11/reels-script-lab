# Stage 05 — Rehook Agent + Rehook Reviewer (restored)

**Полный обязательный регламент:** `references/15-rehook-methodology.md` + `references/16-rehook-reviewer.md`. Отказаться от правила «каждый рехук обязан задавать вопрос». Основной первоисточник: https://www.tatam.com/blog/hook-rehook-framework-for-influencer-briefing

Шесть реальных механизмов из Tatam: `TR-01` heft/proof, `TR-02` contrast, `TR-03` sequential teasing, `TR-04` emotional engagement, `TR-05` question prompt, `TR-06` challenge. Конкретный текст выбирается после 6–9 смыслово разных кандидатов, с тремя разными механизмами на ветку, а не шаблонными вариациями одного «А что, если».

**Вход** — полный контекст выбранного `SRC-*`: фраза до рехука, неизвестное до развязки, реальный следующий бит и payoff. **Выход** — кандидаты, `technique_id`, `specific_pivot`, `next_beat`, `viewer_question`, причины выбора и отказа, отдельный blind review. Авторское объяснение и баллы скрываются от проверяющего. Если не найден сильный кандидат — вернуть `NEEDS_STRUCTURE_REVISION`; не подставлять пустое «но есть нюанс».

Human Language Agent редактирует только речь, не создаёт механику. После речевой правки нужны Rehook Reviewer и Structure Reviewer. Не считать программное обнаружение штампов содержательным независимым ревью.
