# Stage 06 — Script Agent + Script Reviewer

На вход: выбранная ветка, LOCKED hook/rehook, Voice Map с оговорками, Fact Packet, структура, цель, длительность, формат съёмки. Выход: полный текст произнесения, пофразный монтажный план только если запрошен, ориентировочные секунды.

Проверка каждого предложения: наблюдаемое действие / нужный контекст / развивающая интригу информация / объяснение с проверенной опорой / payoff / призыв. Вода, повтор тезиса, лекционный тон и бессмысленные паузы удаляются. Заменять лексику на живую надо *без* изменения проверяемого смысла. Не приписывать зрителю эмоций и мотивов без оснований.

**Строго:** script.lines[0] равно `hook.text`; одна из внутренних строк дословно равна `rehook.text`; последняя равна `cta.text`. `payoff_line_index` расположен строго после рехука. Reviewer проверяет ритм вслух; приблизительные слова/секунды — лишь подсказка. Нельзя обещать ролик «на 30 секунд» при очевидно длинной речевой дорожке. Публичная информация не должна быть подменена общим стереотипом.

Если редактирование нарушило hash хука или обесценило рехук, новая итерация и повторная проверка upstream обязательны.

## Разделение методики и языка (v0.8.1)
Script Writer следует утверждённым хуку, рехуку, структуре, фактам и CTA. Human Language Agent правит лишь способ говорить, а не структуру или аргументы. Script Reviewer обязан повторно проверить смысл после редактуры.


**Восстановленное обязательное дополнение:** `references/17-script-storytelling.md`. Script Reviewer должен проверять развитие по выбранному SRC-ID, переходы через препятствия/следствия, foreshadow и итоговое исполнение обещаний, а не только чередование полей в JSON.
