# Stage 07 — CTA Agent + Reviewer

Выбрать ровно один основной результат в соответствии с `brief.goal`: обсуждение (комментарий с реальной причиной ответить), подписка (объяснить, какая последующая польза будет), переход (точная доступная ссылка или указание, где её найти), заявка/покупка (подтверждённые условия), сохранение/репост (действительно полезная информация), либо no CTA, если это лучше истории.

Не использовать искусственные «напиши + чтобы получить секрет», ложную нехватку мест, несуществующий бесплатный гайд, скрытые продажи или агрессивное давление. Подписку, лид-магнит и продукт добавлять только при подтверждённой цели проекта. Если автор дал свой CTA — не переписывать.

Reviewer: CTA не противоречит материалу, обещание выполнимо, логично завершает именно эту ветку, не разрушает эмоциональный финал и укладывается в хронометраж.


**Первоисточник для CTA Agent:** https://smmbot.net/blog/10-prizyvov-k-dejstviu-cta-v-instagram-dla-povysenia-vovlecennosti-137.html — одно чёткое действие, связанное с целью ролика и доступным ресурсом, без конкурирующих призывов и фиктивной срочности. **CTA Reviewer** должен сравнить CTA с исходной целью брифа, тоном профиля, последней сценой и фактической доступностью обещанного предложения. При отсутствии заявленной в брифе подписки/гайда не добавлять их ради формулы.
