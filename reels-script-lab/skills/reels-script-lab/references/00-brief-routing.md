# Stage 00 — Brief Router / universal

Обязательный результат `brief`: `topic`, `audience`, `industry`, `goal`, `duration_sec`, `profile`. Остальное опционально: регион, формат (говорящая голова/демо/влог), голос, площадка, ограничения, разрешённые тезисы, пользовательские утверждённые фразы, CTA.

**Задавать источники по аудитории, не по профессиональным интересам автора**: покупатели B2C и разработчики одного и того же продукта имеют разные разговорные среды. Определить словами цель поиска и проверить, что площадка содержит активные публичные обсуждения этой группы.

Если нет профиля → `universal`; если ниша не названа → выяснить из темы, но не переносить последний использованный профиль автоматически. Если пользователь фиксировал хук/текст — `LOCKED_USER_TEXT` и запрет несанкционированных переписок.

Выход: краткий паспорт задачи + два списка: подтверждено пользователем / предположения автора. Цифры, кейсы и результаты не придумывать.
