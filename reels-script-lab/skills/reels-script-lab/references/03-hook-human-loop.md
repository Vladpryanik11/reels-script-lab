# Stage 03 — Hook Formula Agent + Hook Reviewer ↔ отдельный Human Language Agent

**НЕ путать**: `references/12-hook-formula-library.md` — техника привлечения внимания из пользовательских учебных ссылок. `references/11-human-language-agent.md` — живой русский язык по текстам/комментариям. Первый отвечает за **что и зачем сказать**, второй — **как естественно произнести уже задуманное**.

## Два независимых потока

**Hook Formula Agent → Hook Reviewer**: берёт Brief, факт-досье, библиотеку хуков пользователя, режим утверждённых шаблонов. Выбирает формулу и угол, делает кандидатов, фиксирует `source_id`, `formula_id`, `viewer_question`, `payoff_contract`, визуальный первый кадр. Reviewer проверяет механизм удержания и соответствие сценарию, вправе отвергнуть все. Ни одна публикация с бытовым комментарием не используется как `formula_id`.

**Human Language Agent → Human Language Reviewer**: ищет реальные тексты людей, строит Language Map, выявляет особенности неформального русского языка. Получает готовый формульный хук и редактирует **только речь**, не исходное обещание. Использовать комментарии как фразы-образцы, не как формулы и не как обязательные сюжеты. Если речь требует смыслового пересмотра — запросить новую кандидатуру у Hook Formula Agent.

**Обратный контроль**: Hook Reviewer вновь получает исходный формульный хук и речевую версию. Если редакция убрала интригу, поменяла фактическое утверждение, обещание, первый кадр или зрительский вопрос — `REJECT` и возврат соответствующему автору. После настоящего утверждения `locked_sha256`, включая авторские шаблоны, никак не менять.

## Когда нет доступа к комментариям

Hook Formula Agent всё равно может подготовить черновики по учебным методикам. Human Language Agent сообщает `SOURCE_INSUFFICIENT` и не приписывает речевой правке реальное обучение из корпуса. Результат `PREVIEW_ONLY`; при отсутствии пользовательского каталога со строгими шаблонами не заявлять, что они соблюдены.

## Тестируемый контракт

Проверить передачу между агентами: `scripts/method_voice_gate.py` и `references/09-contracts.md`. Этот код проверяет разделение и ссылочную целостность, **но не измеряет, насколько хук действительно цепляет** и не доказывает реальные запуски разных ИИ-агентов.


## Ранний Hook ↔ Structure Review до блокировки
До окончательного `locked_sha256` Structure Agent проверяет пригодность кандидата к конкретному `SRC-*`; Hook Reviewer обязан подтвердить, что выбранный сюжет раскрывает обещание исходного Hook. При несовпадении вернуться за другим сюжетным маршрутом/хуком, не менять уже утверждённое молча. Human Language Agent НЕ выбирает драматургию, а лишь редактирует русский язык; после любой речевой правки обязательна повторная проверка Hook Formula Reviewer и совместимости с Structure.
