# Исторический пилот v0.8 — данные для Human Language, НЕ генерация хуков

Старый поток `источник→наблюдение→хук` ошибочно смешивал **знание о людях** с **методикой сильного хука**. Старые кейсы остались только для проверки происхождения наблюдений и речевого редактора. **Не использовать их как формульные тесты.**

Правильная схема: параллельно получить библиотеку пользовательских формул (`references/12-hook-formula-library.md`) и Language Map (`references/11-human-language-agent.md`). Затем Hook Formula Agent пишет *по формуле*, независимый Hook Reviewer проверяет творческую конструкцию, Human Language Agent делает *только языковую* редакцию, и Hook Reviewer снова перепроверяет, не разрушена ли формула.

`scripts/integration_gate.py` сохраняется как регрессионный **legacy**-тест материала обсуждений. Для новой схемы использовать `scripts/method_voice_gate.py`. Офлайн-скрипты не доказывают успешный доступ к публикациям и реальное качество хуков.
