# Public speech evidence — только для Human Language Agent

Это **корпус языка**, а не коллекция готовых хуков и НЕ формульная база. Его изучает `references/11-human-language-agent.md`.

- Подбирать площадки под целевую аудиторию (публичные комментарии, форумы, Threads, Пикабу, Habr, Reddit, vc.ru, профильные отзывы). Не ограничиваться какой-то нишей.
- Открывать страницы, если возможно. Сохранять URL, дату доступа, тип материала, источник полного чтения и различать `FULL_PAGE_OPENED`, `SEARCH_EXCERPT_ONLY`, `UNAVAILABLE`.
- Извлекать **языковые** наблюдения: ритм, длину фраз, синтаксис, речевые связки, живую интонацию, характер юмора, лексику. Ситуации и сомнения аудитории — отдельные заметки для брифа, не формулы хуков.
- Не копировать чужие цитаты в готовый ролик. Не принимать вымышленные `capture_ref` из JSON за факт реального чтения.
- Не утверждать статистическую распространённость наблюдений по нескольким публикациям. Хранить Language/Voice Map как редактируемую библиотеку с датами и фактическими ссылками, не представлять её как дообучение весов LLM.
- Если источники недоступны, вернуть `SOURCE_INSUFFICIENT`; Hook Formula Agent всё ещё вправе писать черновик по подтверждённым формульным источникам, но нет подтверждённого языкового прохода.
