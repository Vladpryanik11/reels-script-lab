# Reels Script Lab Universal v0.8.2 — НЕ смешивать формулу и речь

> Skills-only: роли описаны как последовательный протокол. Это не развернутые отдельные модели, не постоянно работающий сборщик комментариев. Не выдавать self-review за независимое ревью, не обещать удержание без измерений.

**Универсальность:** по умолчанию `profiles/universal.md`. Другие профили подключаются только к явно указанному заданию. Никаких предположений об отрасли и голосе автора.

## Три независимых вида знаний

1. **Hook Formula Agent (формулы и механики первых секунд):** источники — проверенные пользовательские методики хуков и принятые шаблоны из `references/12-hook-formula-library.md`. Проектирует конкретный механизм удержания, возможные визуальные крючки, `viewer_question`, `payoff_contract` и сценарное направление. Имеет отдельного **Hook Reviewer**. НИКОГДА не выводит формулы из комментариев.
2. **Human Language Agent (живая русская речь):** источники — реально доступные тексты, комментарии, отзывы и посты русскоязычной аудитории, разбор ритма, лексики и манеры из `references/11-human-language-agent.md` и `references/01-public-voice.md`. Имеет отдельного **Human Language Reviewer**. Не придумывает формулы, не определяет главную интригу, не обязан брать сюжет из комментария.
3. **Fact Research Agent:** проверяет объективные утверждения независимо от методов и стиля — `references/02-fact-policy.md`. Реальная речь из комментариев не подтверждает фактические/причинные выводы.

## Обязательный конвейер

1. Принять универсальный бриф: `references/00-brief-routing.md` — кто смотрит, ради чего, отрасль, тема, цель видео, голос автора и ограничения.
2. Подготовить две базы **независимо**: библиотека хуков по пользовательским первоисточникам (`references/12-hook-formula-library.md`) и Language Map по реально прочитанным разговорным текстам (`references/11-human-language-agent.md`). Комментарии могут обогащать язык и исследования аудитории, но не заменяют формулы.
3. Fact Research и проверка обещаний — отдельно, по нужным фактам, не автоматически «научные статьи» для любой ниши.
4. **Hook Formula Agent → Hook Reviewer:** по `references/03-hook-human-loop.md`, восстановленный подробный `references/21-hook-methodology.md` и `references/22-hook-reviewer.md` создать несколько конкурентных входов и 3 **разных** концептуальных маршрута; строго использовать принятые формулы и закрытый каталог, если он актуален для выбранного профиля. Reviewer проверяет силу, формулу, ценность, интригу, выполнимость и первый кадр. Если слабые — переделка в Hook Formula Agent, не в комментарии.
5. **Human Language Agent → Human Language Reviewer:** получает уже сформулированный хук и только редактирует лексику/ритм/синтаксис из реальных русскоязычных текстов. При нехватке доступных источников обозначить это. Не менять формулу, обещание, смысл или факт; при необходимости смысловой правки — запросить новый Hook Formula Agent.
6. **Hook Reviewer повторно:** сравнивает черновик и разговорную версию: не исчезли ли крючок, вопрос зрителя, визуальный контраст и обещание. При утрате — REJECT. Контракт: `scripts/method_voice_gate.py` и `references/09-contracts.md`.
7. **Structure + Reviewer**: `references/04-structure.md`, ПОЛНЫЙ `references/13-structure-methodology.md` и независимый `references/14-structure-reviewer.md`; выбирают пригодный `SRC-01…07` до блокировки хука; 3 независимых истории, а не 3 синонима. Если конструкция не раскрывает Hook, совместно с Hook Reviewer вернуться к ранее неопределённому ракурсу; не трогать locked-текст.
8. **Rehook Agent + Rehook Reviewer**: `references/05-rehook.md`, ПОЛНЫЙ `references/15-rehook-methodology.md` + `references/16-rehook-reviewer.md`, генератор `references/18-rehook-generator.md`, оркестратор `references/19-rehook-orchestrator.md`, reviewer prompt `references/20-rehook-reviewer-prompt.md`; 6 механизмов Tatam, слепой просмотр всех кандидатов, дополнительный языковой проход и повторное сценарное ревью.
9. **Script + Reviewer**, **CTA + Reviewer**: `references/06-script.md`, методика Jenny Hoyos/Postium `references/17-script-storytelling.md` и `references/07-cta.md` + `references/23-cta-methodology.md`; речевые правки проходят отдельно, не ломая драматургию и информационный контракт.
10. **Comparative Final Reviewer**: `references/08-final-review.md`; проверить факты, оригинальность, разные структуры, точность формулы и естественность отдельно. Фиксация `locked` только после настоящего утверждения.

## О совместимости и источниках

Исторические примеры `references/10-live-integration.md` — только демонстрация проверки источников и языковых наблюдений; НЕ методика генерации хуков. Локальный `scripts/integration_gate.py` до v0.8.2 проверял «источник→наблюдение→хук» — теперь этот выход считается старым диагностическим кейсом, не авторитетным контрактом Hook Formula Agent. Новый двухпоточный контракт реализован отдельно.

**Статусы:** непрочитанный текст — не прочитанный; поисковый сниппет — не пост; отсутствие language-корпуса не запрещает написание методологического черновика, но запрещает подтверждённый Voice Pass. `SELF_REVIEW_ONLY` ≠ отдельный независимый AI-run. При отсутствии источников или истинной аттестации результат маркируется `PREVIEW_ONLY`.
